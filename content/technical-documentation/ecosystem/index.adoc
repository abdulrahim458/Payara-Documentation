= Connector Suites/Arquillian Containers/Ecosystem/Connector Suites/Arquillian Containers

The Payara Foundation not only provides application servers in the form of Payara
Server and Payara Micro; there are also satellite projects
which complement and enhance the developer experience.

These include:

xref:project-management-tools/maven-plugin/index.adoc[Payara Micro Maven Plugin]::
A plugin for Apache Maven is available for Payara Micro.

xref:project-management-tools/maven-archetype.adoc[Payara Micro Maven Archetype]::
An archetype for Apache Maven is available for Payara Micro.

xref:project-management-tools/gradle-plugin.adoc[Payara Micro Gradle Plugin]::
A plugin for Gradle is available for Payara Micro.

xref:project-management-tools/payara-starter.adoc[Payara Starter]::
An archetype is available for Payara Platform.

xref:ide-integration/eclipse-plugin/index.adoc[Payara Tools Eclipse Plugin]::
A plugin for using Payara is available for Eclipse.

xref:ide-integration/apache-netbeans-ide/index.adoc[Payara Tools for Apache NetBeans]::
The tools for using Payara are available in the Apache NetBeans.

xref:ide-integration/intellij-plugin/index.adoc[Payara IntelliJ IDEA Plugin]::
A plugin for using Payara is available for IntelliJ IDEA.

xref:ide-integration/vscode-extension/index.adoc[Payara Visual Studio Code Extension]::
An extension for using Payara is available for Visual Studio Code.

xref:connector-suites/arquillian-containers/index.adoc[Cloud Connectors]::
Cloud Connectors are a collection of JCA adapters which can interact with popular message brokers, including:
* xref:connector-suites/cloud-connectors/amazon-sqs/index.adoc[Amazon SQS]
* xref:connector-suites/cloud-connectors/apache-kafka.adoc[Apache Kafka]
* xref:connector-suites/cloud-connectors/azure-sb.adoc[Azure Service Bus]
* xref:connector-suites/cloud-connectors/mqtt.adoc[MQTT]

xref:connector-suites/arquillian-containers/index.adoc[Arquillian Containers]::
Arquillian containers help perform integration tests for application servers. There are various containers available for Payara:
* xref:connector-suites/arquillian-containers/payara-micro-managed.adoc[Payara Micro Managed]
* xref:connector-suites/arquillian-containers/payara-server-remote.adoc[Payara Server Remote]
* xref:connector-suites/arquillian-containers/payara-server-managed.adoc[Payara Server Managed]
* xref:connector-suites/arquillian-containers/payara-server-embedded.adoc[Payara Server Embedded]
